# `Turbine.Gameplay.Backpack`

Provides access to a player's backpack.

The backpack holds all the items that a player is carrying. This class can be used to get the size of the backpack and to access any specific item contained within.

**Inheritance:** `Turbine.Object` → **Turbine.Gameplay.Backpack**

## Methods

### `GetItem()`

Gets an item from the player's backpack.

```lua
function Backpack:GetItem(index);
```

**Parameters:**

- `index` (`number`) — The index of the item to get.

**Returns:** [Item](Turbine.Gameplay.Item.md) — Either nil if there is no item there or the index is invalid, or the Item that is in the given index.

This method will return an Item out of the player's backpack at the specified index. The index must be in the range of 1 to GetSize.

### `GetSize()`

Gets the size of the player's backpack.

```lua
function Backpack:GetSize();
```

**Returns:** `number` — The size of the player's backpack.

This returns the size of the player's backpack.

### `PerformItemDrop()`

Function to handle moving or swapping an item in our inventory. This DOES NOT handle dragging items from any of the character banks or housing hooks. For that functionality please use "PerformShortcutDrop.".

```lua
function Backpack:PerformItemDrop(item, destinationIndex, split);
```

**Parameters:**

- `item` ([Item](Turbine.Gameplay.Item.md)) — The LuaItem representing the item you are trying to move
- `destinationIndex` (`number`) — The index into the backpack where you are trying to place the item
- `split` (`boolean`) — Whether or not we want to split the item's stack while dragging it

### `PerformShortcutDrop()`

Function to handle dropping any kind of item into the backpack. If the item is already in the backpack or is coming from a housing hook, it will perform a swap with anything at the destination index.

```lua
function Backpack:PerformShortcutDrop(shortcut, destinationIndex, split);
```

**Parameters:**

- `shortcut` ([Shortcut](Turbine.UI.Lotro.Shortcut.md)) — The LuaShortcut containing the item info needed for handling drag and drop. This MUST be generated by a valid drag and drop message or moving things from the vaults and housing hooks will generate errors!
- `destinationIndex` (`number`) — The index into the backpack where you are trying to drop the item
- `split` (`boolean`) — Whether or not we want to split the item's stack while dragging it
