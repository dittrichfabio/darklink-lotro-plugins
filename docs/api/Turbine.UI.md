# `Turbine.UI` (namespace)

The core UI package that allows users to create low level controls.

## Classes

| Name | Description |
|---|---|

| [CheckBox](Turbine.UI.CheckBox.md) | A control used to indicate a boolean state. |
| [Color](Turbine.UI.Color.md) | Represents a 4 channel color with red, green, blue, and alpha. |
| [ContextMenu](Turbine.UI.ContextMenu.md) | Defines a menu that can be displayed to the user. |
| [Control](Turbine.UI.Control.md) | The base control class for all available user interface elements. |
| [ControlList](Turbine.UI.ControlList.md) | Defines a list of controls. |
| [Display](Turbine.UI.Display.md) | Provides display information. |

| [MenuItem](Turbine.UI.MenuItem.md) | Defines a menu item. |
| [MenuItemList](Turbine.UI.MenuItemList.md) | Defines a list of menu items. |

## Remarks

This UI package contains the base classes for UI controls. These controls have no default interface look and feel, providing the most basic display of various UI elements.For controls that appear like the actual game, see one of the child packages.
