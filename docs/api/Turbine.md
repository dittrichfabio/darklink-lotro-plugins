# `Turbine` (namespace)

The core Turbine API package.

## Classes

| Name | Description |
|---|---|
| [Chat](Turbine.Chat.md) | This class provides events for when messages are received through the game. This includes player chat, tells, in game messages, and announcements. |
| [Engine](Turbine.Engine.md) | Provides engine level information to user plugins. |
| [LotroPluginManager](Turbine.LotroPluginManager.md) | Provides access to plugin management methods. |
| [Object](Turbine.Object.md) | The base object class for API classes. |
| [Plugin](Turbine.Plugin.md) | Provides information about a specific plugin that has been loaded. |
| [PluginData](Turbine.PluginData.md) | Provides the ability to save and load plugin data. |
| [PluginManager](Turbine.PluginManager.md) | Provides access to plugin management methods. |
| [Shell](Turbine.Shell.md) | Provides programmer extensibility to the chat window. |
| [ShellCommand](Turbine.ShellCommand.md) | A command that can be register for use in the chat window. |

## Enumerations

| Name | Description |
|---|---|
| [ChatType](Turbine.ChatType.md) | Defines the type of chat data. |
| [DataScope](Turbine.DataScope.md) | Defines the scope of plugin data. |
| [Language](Turbine.Language.md) | Defines the client languages. |

## Remarks

The Turbine package provides access to core game functionality.
